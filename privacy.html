Privacy policy

Who uses it. This Google OAuth client is used only by its owner, to back up the owner's own home server. No one else signs in to it.

What it accesses. It uses the Google Drive drive.file permission, so it can only see and change files that it created itself in the owner's own Google Drive. It cannot read any other files.

What it stores. Encrypted backup files in the owner's own Google Drive. The sign-in token stays on the owner's own server.

Sharing. No data is collected, sold, shared with third parties, or used for advertising. Google user data is used only to store and retrieve these backups.

Removing access. Access can be revoked at any time at myaccount.google.com/permissions.
